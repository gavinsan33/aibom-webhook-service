{{ .Release.Namespace }} is set up for AIBOM collection. Workloads get an AIBOM only while the namespace carries the opt-in label:

  oc label namespace {{ .Release.Namespace }} aibom.io/enabled=true

List AIBOMs once a workload finishes:  oc get aiboms -n {{ .Release.Namespace }}
Check the install with:  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
