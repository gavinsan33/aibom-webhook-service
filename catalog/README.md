# OpenShift Helm catalog submission

These are the `OWNERS` files for submitting both charts to
[openshift-helm-charts/charts](https://github.com/openshift-helm-charts/charts) as
community charts, laid out the way that repository expects
(`charts/community/<vendor label>/<chart>/OWNERS`). They aren't used by anything in this
repository. See "Publishing to the OpenShift Helm catalog" in
`docs/reference/development.md` for the process. Only the GitHub users listed under
`users` can open the per-version pull requests there.
